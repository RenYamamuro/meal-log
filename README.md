# MEAL LOG（食事・PFC記録アプリ）

食べたものを記録して、カロリーと PFC（たんぱく質・脂質・炭水化物）が
1日の目標に対してどれだけかを見るための自分用Webアプリ。
LIFT LOG と同じく素の HTML + CSS + JavaScript の1ファイル構成で、
データはブラウザの `localStorage`（キー `meal-log-v1`）に保存される（サーバー不要・ログイン不要）。

## できること

1. **今日の合計** — カロリーの輪、P/F/C ごとのバー、残り量、PFCバランス（実際と目標の比較）
2. **食事ごとの記録** — 朝食・昼食・夕食・間食。食品をタップすると量の変更・食事の付け替え・削除ができる
3. **食品から選ぶ** — 内蔵の約50品（主食・肉魚・卵大豆乳・野菜果物・惣菜外食・飲み物間食）から検索 or カテゴリで選ぶ。
   量は「単位」の倍数（0.5刻み、直接入力も可）。「最近」に使った順で並ぶ
4. **手入力とマイ食品** — 栄養成分表示を写して登録。kcal を空けると P×4 + F×9 + C×4 で計算。
   「マイ食品に保存」すると次から選べる（目標タブで削除できる）
5. **履歴** — 直近7日 / 30日のカロリーとたんぱく質の棒グラフ（点線が目標、目標の1.1倍を超えた日は薄く表示）、
   記録した日の平均と PFC バランス、日ごとの一覧（タップでその日へ）
6. **目標** — 性別・年齢・身長・体重・活動量・目的から自動計算、または自分で直接入力
7. **書き出し・読み込み** — JSON でバックアップ

## 目標の計算

- 基礎代謝：Mifflin-St Jeor 式（男性 `10×体重 + 6.25×身長 − 5×年齢 + 5`、女性は `− 161`）
- 消費カロリー：基礎代謝 × 活動係数（1.2 / 1.375 / 1.55 / 1.725）
- 目標カロリー：減量 −400 / 維持 ±0 / 増量 +300 kcal
- P：体重 × g/kg（初期値 2.0）、F：カロリーの %（初期値 25%）、C：残り全部

## 食品の値について

`index.html` の `FOODS`。素材は日本食品標準成分表（八訂）の100gあたりの値を1単位に換算したもの。
`est: true`（画面では「目安」）の惣菜・外食・市販品はよくある値で、店や商品でかなり変わる。
記録には追加した時点の値を写して保存するので、`FOODS` を直しても過去の記録は変わらない。

## 公開URL

https://renyamamuro.github.io/meal-log/

GitHub Pages（`main` ブランチのルート）。更新は `git push` するだけで反映される（反映まで数十秒）。
`sw.js` の中身を変えたときは `CACHE` の版を上げること。

**更新を端末に届ける方法**: iPhone ならアプリスイッチャーで上スワイプして完全に終了させ、
オンライン状態で開き直す。

### ホーム画面に追加

- **iPhone (Safari)** — 共有ボタン → 「ホーム画面に追加」
- **Android (Chrome)** — メニュー → 「ホーム画面に追加」

記録は端末のブラウザの中だけに保存され、端末どうしで同期はしない。
別の端末に移すときは「目標」タブの書き出し・読み込みを使う。

## 手元で動かす

```
python3 -m http.server 8765
```

をこのフォルダで実行して http://localhost:8765 を開く。`index.html` を直接開いても動くが、
Service Worker（オフライン）は効かない。

## ファイル

- `index.html` — アプリ本体（HTML / CSS / JS すべて）
- `sw.js` — オフライン用の Service Worker（ネットワーク優先 + キャッシュ）。中身を変えたら `CACHE` の版を上げる
- `manifest.json`・`icons/` — ホーム画面に追加したとき用
- `fonts/` — LIFT LOG と同じ丸ゴシックの書体
